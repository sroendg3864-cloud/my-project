# 개인 투자관리도구

여러 종목의 매수·매도 기록과 평가손익을 한 곳에서 관리하는 개인용 웹앱입니다.
[기획서 v2](./기획서%20v2.md)의 요구사항을 그대로 구현했습니다.

## 실행 방법

빌드 도구가 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

```
open index.html          # macOS
start index.html         # Windows
```

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (HTML + CSS + JS 단일 파일) |
| `기획서 v2.md` | 요구사항 정의서 |

## 화면

- **포트폴리오** — 총 매수원금·평가금액·평가손익·수익률과 보유 종목 목록
- **종목 상세** — 종목별 손익, 분기별 주가 추이 차트, 매매 이력 (포트폴리오에서 행 클릭)
- **매매 기록** — 매수·매도 입력, 종목·구분별 필터 조회, 삭제
- **종목 관리** — 종목 등록/삭제, 현재가 갱신

## 데이터

- 브라우저 `localStorage`(키: `portfolio-data`)에 저장됩니다. 서버·로그인 없음.
- 브라우저를 바꾸거나 브라우저 데이터를 삭제하면 기록이 사라지므로,
  상단의 **JSON 내보내기**로 주기적으로 백업하세요. **JSON 가져오기**로 복원합니다.
- 시세(현재가, 분기별 종가)는 **직접 입력**합니다. 실시간 API 연동은 Phase 2 항목입니다.

## 계산 규칙

- **평균단가**: 이동평균법. 매수 시 가중평균으로 갱신, 매도 시 평단가는 유지하고 수량만 차감.
- **거래 순서**: 입력 순서가 아니라 **거래일 오름차순**으로 재생해 계산하므로,
  과거 거래를 나중에 입력해도 결과가 맞습니다.
- **실현손익**: (매도단가 − 매도 시점 평단가) × 매도수량
- **수익률**: 평가손익 ÷ 매수원금 × 100 (매수원금이 0이면 `-` 표시)
- 수수료·거래세·배당은 반영하지 않습니다 (Phase 2).

## 참고

- 차트는 Chart.js를 CDN에서 불러옵니다. 사내망 등에서 CDN이 차단되면 차트 자리에
  안내 문구가 표시되고, 나머지 기능은 정상 동작합니다. 오프라인 사용이 필요하면
  Chart.js 파일을 저장소에 함께 두고 `index.html`의 `<script src>`를 로컬 경로로 바꾸세요.
- 데스크톱 브라우저 기준으로 만들었습니다 (모바일 반응형은 Phase 2).

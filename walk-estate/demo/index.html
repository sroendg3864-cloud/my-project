임장로드

가용 자산과 소득으로 실구매 상한가를 역산해 임장 후보지를 추천하고, 현장에서는 보행 전용 경로와 스마트 체크리스트로 안전·교육·주거 환경을 검증합니다. 오른쪽 화면은 목업이 아니라 실제로 동작하는 프로토타입입니다 — Next.js 저장소와 같은 계산식을 씁니다. 아래에 카카오맵 JavaScript 키를 넣으면 체크포인트가 그 동네의 실제 파출소·초등학교·마트·공원으로 바뀌고 지도도 카카오맵으로 그려집니다.

    핵심 계산식

    매매 상한가
    P_buy = (가용현금 + min(LTV 상한, DSR 40% 한도)) × 0.965
    전세 상한가
    P_jeonse = 가용현금 + min(보증금 80%, 연소득 × 4.0)
    지역 추천 점수
    Score_Area = 0.4·S_Turnover + 0.3·S_Density + 0.3·S_BudgetFit
    예상 소요 시간
    ceil(거리 / 80m·분) + 체크포인트 수 × 3분, 급경사 ×1.2

    바로 해보기

    지역명·거래량·수요밀도·경로는 데모용 시뮬레이션 데이터입니다. 지도는 API 키 없이 도는 0~100 가상 좌표 캔버스이며, 실제 지도로 옮길 때는 waypoint의 x·y를 위경도로 바꾸면 됩니다. 임장 진행 상황은 브라우저에 저장되어 새로고침해도 이어집니다.

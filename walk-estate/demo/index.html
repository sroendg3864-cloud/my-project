임장로드

가용 자산과 소득으로 실구매 상한가를 역산해 임장 후보지를 추천하고, 현장에서는 보행 전용 경로와 스마트 체크리스트로 안전·교육·주거 환경을 검증합니다. 오른쪽은 목업이 아니라 실제로 동작하는 프로토타입입니다 — 실제 도로망 위에 그 동네의 실제 파출소·초등학교·도서관·마트·공원을 찍어 경로를 만듭니다. 지도와 장소는 OpenStreetMap 실측 데이터라 API 키가 없어도 그대로 동작합니다.

    P_jeonse = 가용현금 + min(보증금 80%, 연소득 × 4.0)
    지역 추천 점수
    Score_Area = 0.4·S_Turnover + 0.3·S_Density + 0.3·S_BudgetFit
    예상 소요 시간
    ceil(거리 / 80m·분) + 체크포인트 수 × 3분, 급경사 ×1.2

    지금 무엇이 실제 데이터인가

    항목출처상태
    지도 · 도로망OpenStreetMap 실측 지오메트리 (도로·철도·공원·수계)실데이터
    체크포인트 장소OSM 실제 POI — 파출소·치안센터·초등학교·도서관·마트·공원·역, 안전 지점은 실제 도로명 위에 배치실데이터
    인구밀도서울 자치구 인구/면적 실측치실데이터
    도보 경로 · 거리카카오 도보 길찾기는 제휴 파트너 전용 — 직선거리 ×1.25 근사, Tmap 키를 넣으면 실측근사
    경사 · 계단고도 데이터가 없어 급경사 배지는 실좌표 모드에서 숨김미지원
    시세 · 거래량국토교통부 아파트 실거래가 — 공공데이터포털 서비스키 필요데모값

    바로 해보기

    지역명·거래량·수요밀도·경로는 데모용 시뮬레이션 데이터입니다. 지도는 API 키 없이 도는 0~100 가상 좌표 캔버스이며, 실제 지도로 옮길 때는 waypoint의 x·y를 위경도로 바꾸면 됩니다. 임장 진행 상황은 브라우저에 저장되어 새로고침해도 이어집니다.
